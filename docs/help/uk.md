# Посібник користувача AdminCraft

AdminCraft зберігає всі ваші сервери, комутатори й ПК в одному списку та відкриває їх подвійним клацанням:
віддалений робочий стіл, SSH, VNC, Telnet, PowerShell, веб-інтерфейси й передавання файлів, кожне у власній вкладці.
Крім того, він має щоденні інструменти адміністратора: ping, сканування портів, сканування мережі, DNS,
калькулятор підмереж, перевірку сертифікатів та інше.

Цей посібник є і в самій програмі: **Довідка » Посібник користувача** або **F1**.

## Вікно з першого погляду

![Головне вікно AdminCraft](../images/main.png)

```
+---------------------------------------------------------------------------+
| Файл  Вигляд  Інструменти  Довідка                                        |
| Швидке підключення [SSH v] [хост або IP] Підключитися | Ping  ...         |
+-----------------+-------------------------------------+-------------------+
| Підключення     |  [Головна] [web01] [DC01] [Файли]  <- вкладки           |
|  пошук ...      |                                     | Властивості       |
|  > ЦОД          |   відкрите підключення, інструмент  |  ім'я, хост,      |
|     DC01        |   або стартова сторінка             |  вхід, параметри  |
|     web01       |                                     |  вибраного        |
|  > Мережа       |                                     |  підключення      |
+-----------------+-------------------------------------+-------------------+
| Підключень: 16 · папок: 3 | стан майстер-пароля | де зберігається список  |
+---------------------------------------------------------------------------+
```

- **Ліворуч: дерево підключень.** Папки й підключення. Подвійне клацання відкриває, клацання правою кнопкою показує
  все, що можна зробити із записом.
- **Посередині: вкладки.** Кожне відкрите підключення чи інструмент отримує вкладку. Вкладка **Головна** показує картки
  швидкого старту, скільки підключень використовують який протокол і які допоміжні програми знайдено.
- **Праворуч: властивості.** Усе про вибране підключення чи папку. Зміни зберігаються
  самі за мить.
- **Угорі: швидке підключення.** Виберіть протокол, введіть `host`, `user@host` або `user@host:port` і натисніть Enter —
  для разового підключення, яке ви не хочете зберігати.
- **Унизу: рядок стану.** Кількість підключень, чи захищає список майстер-пароль
  і де зберігається список.

> Порада: Вигляд » Показувати властивості ховає праву частину, коли потрібно більше місця.

## Ваше перше підключення

1. Натисніть **+ Підключення** (або **Ctrl+Shift+N**).
2. Праворуч дайте йому **ім'я**, виберіть **Протокол** (наприклад, SSH або RDP) і введіть
   **хост або IP-адресу**. Порт заповнюється автоматично.
3. У розділі **Вхід** укажіть **Користувач** і, за бажанням, **Пароль** (див. *Паролі* нижче).
4. Двічі клацніть підключення в дереві. Воно відкриється в новій вкладці.

Ось і все. Потрібно кілька схожих серверів? Права кнопка » **Копіювати / дублювати** і змініть лише хост.

> Порада: приклади підключень у новому списку показують, що можливо. Видаліть їх, коли захочете.

## Папки й порядок

- **+ Папка** створює папку; клацніть папку правою кнопкою, щоб вибрати **Нове підключення тут** і **Нова підпапка**.
- **Перетягування:** перетягніть підключення на верхню або нижню половину іншого запису, щоб поставити його перед
  ним або після нього; відпустіть на середині папки, щоб перемістити всередину.
- Права кнопка » **Вгору / Вниз** робить те саме через контекстне меню.
- **Пошук** над деревом (Ctrl+Shift+F) фільтрує за ім'ям, хостом і користувачем.

**Папки передають налаштування далі.** Укажіть користувача, домен і пароль на папці, і кожне підключення в ній
з увімкненим *Брати порожні поля з папки* використовуватиме їх. Змініть пароль адміністратора один раз на
папці, а не на п'ятдесяти серверах. Властивості показують синім, звідки взято значення.

Права кнопка на папці » **Відкрити всі підключення в папці** відкриває їх усі одразу.

## Протоколи: що де відкривається

| Протокол | Відкривається як | Потрібно |
|---|---|---|
| SSH | вкладка термінала (або PuTTY, або окреме вікно) | OpenSSH (вбудований у Windows 10/11, macOS, Linux) або PuTTY |
| RDP | вікно віддаленого робочого столу у вкладці (Windows) | `mstsc` (Windows), FreeRDP або Remmina (Linux), Windows App (macOS) |
| VNC | вікно переглядача у вкладці | переглядач VNC, наприклад TigerVNC або TightVNC |
| Telnet | вкладка термінала | — |
| PowerShell | вкладка термінала з `Enter-PSSession` | PowerShell, WinRM на цільовому комп'ютері |
| HTTP / HTTPS | вікно браузера у вкладці | Edge або Chrome (інакше звичайний браузер) |
| SFTP / SCP / FTP / FTPS | вкладка передавання файлів | OpenSSH або PuTTY для SFTP/SCP; FTP вбудовано |
| Serial, raw TCP, rlogin | PuTTY у вкладці або вкладка термінала | PuTTY/plink (Windows); picocom, nc … в інших системах |
| Локальна оболонка | вкладка термінала на цьому комп'ютері | — |

**Вікна у вкладках.** У Windows вікна віддаленого робочого столу, PuTTY, VNC і веб розміщуються у
вкладці. Клацніть у вікно, щоб вводити текст. **Окремим вікном** знову від'єднує його, **Фокус** передає йому клавіатуру.
У Linux і macOS ці програми працюють в окремих вікнах, а вкладка показує їхній стан.

**Вкладка термінала** розуміє кольори й повноекранні програми (top, htop, mc, vim). На її панелі є
**Перепідключитися**, **Команди** (збережені команди), **Копіювати текст**, **Надіслати пароль** і **Ctrl+C**.

## Паролі

Для кожного підключення виберіть у полі **Пароль з**:

- **В AdminCraft (зашифровано)** — зберігається в списку в зашифрованому вигляді.
- **KeePass** — читається з бази даних KeePass або KeePassXC (запис за назвою або шляхом). AdminCraft запитує
  пароль бази даних один раз за сеанс (Інструменти » Розблокувати KeePass).
- **Запитувати щоразу** — нічого не зберігається.

**Автоматичний вхід:** для SSH і Telnet пароль вводиться, коли сервер його запитує
(Налаштування » *Автоматично вводити збережений пароль у терміналі*). Для RDP він передається Windows
лише для цього підключення.

**Майстер-пароль** (Налаштування » Місце зберігання): без нього збережені паролі лише замасковано — будь-хто
з файлом і AdminCraft може їх прочитати. З майстер-паролем вони надійно зашифровані
(AES-256-GCM, Argon2), і можна **зашифрувати весь список** (також імена й хости).
Тоді AdminCraft запитує майстер-пароль під час запуску.

> Важливо: без майстер-пароля шляху назад немає. Запишіть його й зберігайте в надійному місці.

**Коди 2FA:** записи KeePass із секретом TOTP показують поточний код поруч із паролем.
**Генератор паролів:** Інструменти » Генератор паролів або кнопка *Згенерувати* поруч із полем пароля.

### KeePass як список підключень

Уже користуєтеся KeePass або KeePassXC? Тоді тримайте там увесь список підключень:

1. Налаштування » Сховище паролів: вкажіть базу (`.kdbx`) і натисніть **Розблокувати …**.
2. Натисніть **Зберігати список підключень у KeePass**.

Кожне підключення стає звичайним записом KeePass у групі **AdminCraft** — назва, користувач, пароль,
URL (напр. `ssh://10.0.0.30:22`) і нотатки; папки стають групами KeePass. Їх можна редагувати й у KeePass;
AdminCraft це помічає й перечитує. Запис, створений у KeePass у цій групі (з URL на кшталт `rdp://10.0.0.10`),
з'являється як підключення. Під час запуску AdminCraft запитує майстер-пароль KeePass.
**Назад до власного списку AdminCraft** у тому ж місці копіює список назад.

**Зберегти пароль у KeePass …** (для підключення з *Пароль з » KeePass*): введіть пароль один раз;
AdminCraft кладе його в групу *AdminCraft* вашої бази й надалі використовує цей запис.

## Проміжні хости

До деяких серверів можна дістатися лише через інший сервер («проміжний хост», jump host або bastion).
У розділі **Проміжний хост** у властивостях цільового підключення виберіть проміжне підключення і спосіб переходу:

- **Продовжити на проміжному хості: «ssh user@target»** — AdminCraft входить на проміжний хост і вводить там `ssh user@target`.
  Підходить, коли SSH-ключ для цілі лежить **на проміжному хості**.
- **Тунель через проміжний хост (ssh -J)** — ваш комп'ютер підключається через проміжний хост; ключ залишається у вас.

Проміжні хости можна об'єднувати в ланцюжок (проміжний хост сам може мати проміжний хост). Це працює у вкладці термінала,
з PuTTY і в окремому вікні.

## Передавання файлів

Права кнопка на SSH-підключенні » **Передати файли (SFTP)** або відкрийте підключення SFTP/SCP/FTP.

```
+------------------------------+------------------------------+
| Цей комп'ютер                | Сервер                       |
|  C:\Users\me\Downloads       |  /var/www                    |
|  report.pdf        -->       |  index.html                  |
|                    <--       |  logs/                       |
+------------------------------+------------------------------+
```

- Ліворуч ваш комп'ютер, праворуч сервер. **Вивантажити** і **Завантажити** копіюють вибрані файли або папки.
- **Нова папка**, **Перейменувати**, **Видалити** працюють з обох боків. Файли можна перетягувати з
  файлового менеджера.
- Які програми виконують роботу, задається в Налаштування » *Передавання файлів через* (OpenSSH, psftp/pscp від PuTTY
  або автоматично). FTP і FTPS (TLS) вбудовано.

## Інструменти для адміністраторів

Усі інструменти є в меню **Інструменти**, у кнопках угорі та в контекстному меню підключення
(тоді хост уже заповнено).

- **Ping / Traceroute** — чи доступний хост і яким шляхом ідуть пакети?
- **Сканування портів** — які служби відповідають (SSH, RDP, HTTPS, SMB …)? Поширені порти вже вибрано.
- **DNS-запит** — записи A, AAAA, MX, TXT, CNAME, NS, SOA, PTR, SRV, CAA для імені.
- **Wake-on-LAN** — вмикає ПК через мережу; укажіть його MAC-адресу у властивостях.
- **Калькулятор підмереж** — `192.168.10.77/26` дає мережу, маску, broadcast, першу й останню адресу.
  Одне клацання сканує цей діапазон.
- **Перевірити сертифікат** — скільки днів ще дійсний сертифікат HTTPS, хто його видав, чи він довірений.
- **SSH-тунелі** — переадресація портів для кожного підключення (`local port → host:port` на віддаленому боці),
  запускаються вручну або разом із підключенням.
- **Перевірити стан** (кнопка над деревом) — перевіряє порт кожного підключення й розфарбовує точки в дереві.
- **Керування Windows** (права кнопка на сервері Windows) — служби, перегляд подій, керування комп'ютером,
  спільний ресурс `C$`, **Перезапустити** і **Вимкнути** (з підтвердженням). Сервери Linux можна перезапускати через SSH.
- **Множинне введення** — вводьте те саме в кілька SSH-вкладок одночасно (Інструменти » Множинне введення).
- **Збережені команди** — у вкладці термінала в розділі *Команди*; заповнювачі `{host}` `{user}` `{name}`.

- **Whois** — кому належить домен або IP-адреса, з реєстратором і датами.
- **Перевірка заголовків HTTP** — проходить кожне перенаправлення вебадреси, показує коди стану, заголовки
  й час, перевіряє заголовки безпеки (HSTS, CSP …) і прапорці cookie.
- **Запит SNMP** — опитує комутатор, принтер або сервер (SNMP v2c, community напр. `public`) про назву,
  опис, час роботи, розташування та інтерфейси зі станом, швидкістю й трафіком. Можна обійти будь-який OID.
- **Записи** — відтворює записані сеанси термінала (див. нижче).

### Запис сеансів

Налаштування » Сеанси й моніторинг » **Записувати сеанси термінала для відтворення**: відтоді кожна вкладка
SSH, Telnet, PowerShell і оболонки записується з таймінгом; вкладка показує **• запис**.
Інструменти » **Записи** показує їх, найновіші першими. **Відтворити**, **Пауза**, швидкість (до 16×) і
повзунок працюють як у відео; **Скорочувати паузи** пропускає довгі очікування. Файли (`.cast`) можна
відтворити й в asciinema.

> Записи містять усе, що показував екран. Сервери не показують введені паролі, тож їх там немає — але
> все одно тримайте папку приватною.

## Сканування мережі

![Калькулятор підмереж](../images/subnet.png)

Сканування мережі (Ctrl+Shift+L) шукає пристрої в діапазоні IP, як Angry IP Scanner:

1. Введіть діапазон: `192.168.1.0/24`, `10.0.0.1-50` або `10.0.0.250-10.0.1.5`.
2. Виберіть порти для перевірки й натисніть **Старт**.
3. Кожен пристрій, що відповідає, показує своє ім'я, MAC-адресу, час відповіді та відкриті порти.

**Зберегти як основу для порівняння** запам'ятовує результат. Наступне сканування того самого діапазону позначає кожен пристрій як
**новий**, **зник** або **змінено** (наприклад, інша MAC-адреса) — зручно, щоб помітити чужі пристрої в мережі.

**+ Підключення** біля результату створює підключення в папці *Сканування мережі*; виберіть протокол
зі списку.

## Спільний доступ і централізоване зберігання

![Діалог експорту](../images/export.png)

**Експорт для колеги** (Файл » Експортувати підключення або права кнопка на папці » Експортувати папку):

- **Без паролів** — безпечний варіант за замовчуванням.
- **Зашифровано паролем експорту** — повідомте колезі пароль іншим способом (телефоном).
- **Відкритим текстом** — лише після чіткого попередження; будь-хто, хто отримає файл, зможе прочитати паролі.

**Імпорт** через Файл » Імпортувати експорт AdminCraft. Імпортовані записи потрапляють в окрему папку.

**Централізований список для команди** (Налаштування » Місце зберігання): зберігайте список у **мережевій папці** (SMB,
напр. `\\server\it\AdminCraft-Connections.json`) або на **WebDAV-сервері** (Nextcloud, ownCloud, IIS).
Захистіть його майстер-паролем. Коли колега щось змінює, AdminCraft перезавантажує список.

**Перехід з інших інструментів:** Файл » Імпортувати файл mRemoteNG (`confCons.xml`, з паролями) і
Файл » Імпортувати конфігурацію OpenSSH (`~/.ssh/config`, разом із ProxyJump).

## Налаштування

Відкриваються кнопкою **Налаштування**, клавішами **Ctrl+,** або через Інструменти » Налаштування.

- **Мова** — за замовчуванням мова системи; змінюйте будь-коли.
- **Оформлення** — темне чи світле, розмір шрифту термінала.
- **SSH, віддалений робочий стіл і файли** — який клієнт відкриває SSH (вбудований термінал, PuTTY, окреме вікно),
  які програми передають файли, чи вбудовуються вікна у вкладки.
- **Програми** — де AdminCraft знайшов кожну допоміжну програму. Укажіть власний шлях або просто покладіть
  портативні програми в папку **Папка програм** (`AdminCraftTools` поруч з AdminCraft).
- **Місце зберігання** — де зберігається список, майстер-пароль, централізоване зберігання.
- **Сховище паролів** — яку базу даних KeePass використовувати.

- **Оновлення** — **Перевірити оновлення** запитує в GitHub найновішу версію й пропонує сторінку
  завантаження. AdminCraft ніколи не перевіряє сам.
- **ШІ-агенти** — чи можуть ШІ-асистенти й скрипти на цьому комп'ютері керувати відкритим вікном і чи можуть
  вони також вводити текст у вкладки термінала (вимкнено, доки ви не ввімкнете).
- **Сеанси й моніторинг** — повторно відкривати останні підключення під час запуску, текстові журнали,
  записи для відтворення, регулярна перевірка досяжності.
- **Сховище паролів** — також KeePass як увесь список підключень.

## Портативність: усе поруч із програмою

AdminCraft — це один файл. Усе, що він зберігає, лежить у папках поруч із ним:

```
AdminCraft.exe
AdminCraftData\     підключення, основи для порівняння, журнали сеансів, записи
AdminCraftTools\    допоміжні програми, які ви поклали (putty.exe, vncviewer.exe …)
AdminCraftLang\     ваші власні мовні файли
```

Скопіюйте папку на USB-накопичувач — і весь ваш набір інструментів завжди з вами. Якщо в папку не можна записувати
(наприклад, усередині застосунку macOS), AdminCraft використовує `.admincraft` у вашій домашній папці.

AdminCraft сам нічого не надсилає в інтернет — лише до хостів, до яких ви підключаєтеся.

Єдиний виняток: GitHub, коли ви натискаєте *Перевірити оновлення*.

## Мови

Англійська, німецька, французька, італійська й українська вбудовані. Щоб додати мову або покращити наявну:

1. Налаштування » Мова » **Відкрити папку мов**.
2. Скопіюйте `de.lang.example`, наприклад, як `es.lang`, задайте `@name` і `@code` на початку.
3. Перекладіть текст праворуч від ` = ` у кожному рядку. Ліва частина — англійський оригінал, вона не змінюється.
   `{0}`, `{1}` — заповнювачі, вони мають залишитися.
4. Виберіть мову в налаштуваннях.

Файл там із кодом вбудованої мови (наприклад, `fr.lang`) покращує цю мову.
Цей посібник можна перекласти так само: збережіть його як `help-xx.md` у папці мов.

## Клавіатурні скорочення

| Клавіші | Що робить |
|---|---|
| Ctrl+Tab / Ctrl+Shift+Tab | наступна / попередня вкладка |
| Ctrl+Shift+W | закрити вкладку |
| Ctrl+Shift+N | нове підключення |
| Ctrl+Shift+F | пошук підключень |
| Ctrl+Shift+S | знімок вкладки в буфер обміну |
| Ctrl+Shift+E | експортувати підключення |
| Ctrl+Shift+L | сканування мережі |
| Ctrl+, | налаштування |
| F1 | цей посібник |
| Подвійне клацання | відкрити підключення / перейменувати вкладку |
| Середня кнопка миші | закрити вкладку |

Скорочення використовують Shift, тож програми у вкладці термінала зберігають власні клавіші Ctrl. У macOS використовуйте Cmd
замість Ctrl. Вкладки можна перетягувати, щоб змінити порядок; клацніть вкладку правою кнопкою, щоб перейменувати її.

## Для скриптів і ШІ-агентів

Ті самі інструменти працюють без вікна й виводять JSON. Паролі ніколи не повертаються.

```
admincraft cli list [filter]          збережені підключення
admincraft cli scan 192.168.1.0/24    сканування мережі, порівняння зі збереженою основою
admincraft cli ports <host> [ports]   сканування портів
admincraft cli dns <name>             DNS-запит
admincraft cli subnet <cidr>          калькулятор підмереж
admincraft cli cert <host> [port]     перевірка сертифіката
admincraft cli open <name>            відкрити підключення у вікні
admincraft mcp                        MCP-сервер для ШІ-асистентів (stdin/stdout)
```

**Керування відкритим вікном.** Коли AdminCraft відкрито, агенти можуть працювати і з ним — як колега,
що дивиться через плече (Налаштування » ШІ-агенти вмикає або вимикає це):

```
admincraft cli window tabs              відкриті вкладки
admincraft cli window read 2            що показує вкладка 2
admincraft cli window tool ping web01   відкрити вкладку інструмента
admincraft cli window switch 2          вивести вкладку наперед
admincraft cli window type 2 uptime     ввести в термінал + Enter
```

MCP-сервер пропонує те саме як інструменти `window_…`. Вводити текст у термінали можна лише після дозволу в
налаштуваннях, і кожне введення показується у вікні. Під'єднатися можуть лише програми на цьому комп'ютері,
які можуть читати папку даних; паролі ніколи не видаються.

## Запитання та проблеми

**«Програму не знайдено»** — вкладка **Головна**, *Перевірка системи*, показує, яких допоміжних програм бракує. Встановіть
їх, укажіть шлях у Налаштування » Програми або покладіть їх у папку програм і натисніть *Шукати знову*.

**SSH: «Remote side unexpectedly closed network connection» за проміжним хостом** — ключ для
цілі, імовірно, лежить на проміжному хості. Виберіть спосіб переходу *Продовжити на проміжному хості*.

**Вікно віддаленого робочого столу не з'являється у вкладці** — зачекайте кілька секунд (запити щодо сертифіката
спочатку з'являються окремим вікном), потім натисніть *Перепідключитися*. Налаштування » *Вбудовувати вікна RDP, PuTTY і VNC
у вкладку* вимикає вбудовування.

**Забули майстер-пароль** — зашифровані паролі неможливо відновити. Почніть із порожнього списку
(перемістіть файл з `AdminCraftData` в інше місце) та імпортуйте експорт.

**Де мої дані?** — Файл » Відкрити папку даних.

**AdminCraft під час запуску запитує пароль KeePass** — список підключень зберігається в KeePass. Введіть
майстер-пароль KeePass або натисніть *Без KeePass*, щоб почати з власного (порожнього) списку AdminCraft.
